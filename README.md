# NOVA — итоговый проект по HTML/CSS и frontend-разработке

Адаптивный одностраничный сайт концептуальной платформы цифрового обучения. Создан без фреймворков и сервера.

## Состав
- `index.html` — семантическая разметка.
- `styles.css` — оформление, анимации и адаптивная верстка.
- `script.js` — мобильная навигация и проверка формы.

## Соответствие заданию
- **HTML:** `header`, `nav`, `main`, `section`, `article`, `form`, `footer`, заголовки и ссылки.
- **Дизайн:** типографическая иерархия, общая палитра, карточки, отступы.
- **Адаптивность:** media queries на `1000px`, `700px`, `380px`.
- **Псевдоклассы/псевдоэлементы:** `:hover`, `:focus-visible`, `:nth-child`, `::before`, `::placeholder`.
- **Анимации:** `@keyframes levitate` и `transition`.
- **Flexbox/Grid:** меню/кнопки — Flexbox, основные секции/карточки — Grid.
- **CSS-переменные:** `--bg`, `--text`, `--accent`, `--radius` и другие.
- **Форма:** имя, email, select и checkbox, проверка и сообщения об ошибках.
- **Позиционирование:** `position: sticky`, `relative`, `absolute`.
- **JS:** обработка формы и меню, обновление года в футере.

**Важно:** форма демонстрационная, ничего не отправляет на сервер и не собирает данные. Для GitHub Pages сервер не нужен.

## Публикация на GitHub Pages
1. Создать публичный репозиторий на github.com с именем `nova-frontend`.
2. Загрузить в корень репозитория файлы `index.html`, `styles.css`, `script.js` и `README.md` (не архив целиком).
3. В репозитории открыть **Settings → Pages → Build and deployment**.
4. Выбрать **Deploy from a branch** → **main** → **/(root)** → **Save**.
5. Подождать публикации и открыть ссылку, показанную в Pages, обычно `https://ВАШ-ЛОГИН.github.io/nova-frontend/`.

## Локальный запуск
Открыть `index.html` в браузере (подключение к интернету нужно только для загрузки шрифта Manrope; есть системный запасной шрифт).
